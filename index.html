COACH’S DESK

Keep the team on the same page.

Edit a row in the team Google Sheet. No coding or pull requests are needed for team content.

The team editor has not been connected yet.
  1. Updates: add a date, title, and message. Set pinned to TRUE for priority reminders.
  2. Schedule: add a date, start/end time, type, title, pool, and instructions. Use Pacific local times in 24-hour format (15:30).
  3. Set published to TRUE to display it. Edit the row to correct it, or FALSE to hide it.
  4. Google publishing may take a few minutes. Refresh this page for the latest information.

Published tabs are public, including rows hidden on this website. Keep student contact details, medical information, and private discussions out of the published sheet.

One-time setup for the site owner
  1. Create a dedicated Google Sheet for public team content.
  2. Create an Updates tab with these headings in separate columns: published,date,title,body,category,pinned,link.
  3. Create a Schedule tab with: published,date,time,end_time,type,title,location,notes,link.
  4. Format dates and times as Plain text. Use YYYY-MM-DD and HH:mm. Use TRUE/FALSE for published and pinned.
  5. Publish each tab separately: File → Share → Publish to web → CSV. Enable automatic republishing. Keep editing restricted.
  6. Paste the two published CSV URLs and normal sheet edit URL into TEAM_CONFIG in index.html. Commit once.
  7. Share Sheet edit access with Coach Eberth, then verify a real update and event.

Use one row per practice or championship session. Unknown times can be blank. Calendar downloads are snapshots. Photos and image uploads are not included yet.
