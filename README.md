# Interlake Swim & Dive

A student-maintained website for Interlake High School’s boys’ swim and dive team.

- [Team website](https://ihsswim.vercel.app/)
- [Post updates](https://ihsswim.vercel.app/admin.html)

Coach Eberth and Max can sign in to write updates and add photos. Parents can read published updates without an account.

The site is hosted on Vercel. Posts are stored in Firebase, and uploaded photos are stored in the dedicated team Google Drive. Schedule information is maintained in `team-data.js`.

## Asset credits
